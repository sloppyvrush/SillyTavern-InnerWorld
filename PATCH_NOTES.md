# InnerWorld — промежуточные изменения по рабочей заметке

Исходная версия: **0.5.4** (загруженный пользователем архив). Это **рабочая сборка для проверки**, не окончательный релиз. Версию в `manifest.json` намеренно не повышали до живого тестирования. GitHub и установленные экземпляры SillyTavern не менялись.

## Изменения в коде

1. **Сюжетное время.** Дополнительное распознавание дат внутри обычного повествования (например, «на дворе 17 мая 1996 года», «сейчас май 1996 года»), учёт даты и таймскипов из сообщения игрока до ответа модели, сохранение служебного состояния времени в метаданных сообщений без вставки текста в ролевую. При повторном определении календаря уже установленная дата не заменяется более старой догадкой модели. Текущая обработка не гарантирует распознавание любого произвольного формата даты.
2. **Возраст и тип личности.** Новые форматы даты рождения: словесная дата, восемь цифр слитно, компоненты через пробел. Проверка невозможных дат. Первоначально сохранённые MBTI и темперамент не перезаписываются случайным результатом очередного анализа; в инструкции модели добавлены критерии по осям MBTI.
3. **Анализ во время ролевой.** После первого заполнения дневника обычный анализ использует сохранённое состояние и установленное количество последних сообщений без повторной передачи полных карточек. При полном анализе карточки доступны. Новые встреченные NPC по-прежнему могут получать точечные сведения из списка персонажей/лорбука.
4. **Сны и мысли перед сном.** Новый независимый от «Мечты жизни» блок для персоны, основного чара и встреченных NPC. При сцене засыпания/пробуждения модель может возвращать `before_sleep` и `night_dream`; записи сохраняются между обычными анализами. Не требуется явное описание сна в ответе ролевого бота. Это первая версия эвристики, требующая реальных тестов сцен сна.
5. **Лавка.** Одна общая витрина предлагаемых наград `state.shop` на чат, одинаковая с разных вкладок, с возможностью покупки памятных вещей для бота и персоны. При переходе со старых данных содержимое лавки основного персонажа переносится в общую без повторного запроса.
6. **Предпочтения и теги.** Дополнительные категории и сворачиваемые группы уже выбранных тегов и каталога выбора. Кнопка задания индивидуальных ключей/`re:`-регулярных выражений. В основном ролевом контексте по умолчанию передаются предпочтения, подходящие недавней сцене; режим постоянной передачи сохранён. Этот механизм эвристический и требует проверки на разных формулировках.
7. **Инфоблок и диагностика.** Настраиваемая плашка над/под чатом с сюжетной датой, временем, сезоном, ближайшей датой, явно описанной погодой и настроениями; события диагностики анализа, приблизительный объём токенов, скорость обработки, источники сюжетного времени, факт передачи блоков контекста и события сна. Данные отладки выводятся **в интерфейсе**, а не как сообщения модели. Реальный токенизатор моделей не подключён, поэтому подсчёт токенов — оценочный.
8. **NPC и настройки.** Сохранение экрана настроек после удаления записи; уточнён порядок распознавания личного знакомства персоны с NPC из предыстории (родители, знакомые, бывшие и т. п.). Существующая система восстановления NPC сохранена.
9. **Достижения.** Добавлен интервал не менее восьми сообщений бота между автоматически выдаваемыми достижениями.
10. **Праздники.** Дополнен промпт настройки календаря для эпох и смешанных сеттингов, усовершенствован визуальный список. Базовое правило по Хэллоуину в России девяностых уже было в исходном коде и проверено тестом.

## Что проверено

- `node tests/core.test.mjs` — тесты исходной версии проходят.
- `node tests/improvements.test.mjs` — новые регрессионные сценарии проходят.
- `node --check` — синтаксис изменённых `.js` файлов корректен.
- `git diff --check` — ошибок форматирования патча не обнаружено.

## Что **ещё НЕ проверено или НЕ реализовано полностью**

- **Живые тесты в SillyTavern** (включая Таверну «139»), реальные запросы к API, влияние на генерацию ролевого ответа, прогон всех 14 тем и мобильный интерфейс. Локальный рантайм SillyTavern в этой среде отсутствует.
- Полный архив переписок Claude: был передан только манифест со ссылками на отдельные ZIP, которые не удалось загрузить. Основа — рабочая заметка и прикреплённая сводка.
- Полный пересмотр и балансировка мудлетов/эмоций по механикам The Sims: длительность, замещение, сила и влияние на поведение.
- Всесторонний аудит распознавания NPC (семья персоны, NPC по слухам, умершие, переход серого профиля в открытый); уточнения инструкции модели не гарантируют правильное поведение в каждом сюжете.
- Точный учёт токенов по реальному токенизатору и эмпирическое сравнение качества ролевой с выключенными/включёнными механиками.
- Исчерпывающий каталог исторических праздников для всех стран и эпох. Встроенные списки дат есть для России и США, остальные страны зависят от модельной генерации.
- Полное отслеживание каждого события и каждой отправленной в модель инструкции на уровне API, а также сложные правила активации предпочтений по логике SillyTavern World Info.
- Подтверждение правильного поведения новых снов при многократном сне, перегенерации ответа, переключении чатов и в параллельном режиме.

## Как проверить

1. **Сделать копию папки установленного расширения** и чатов SillyTavern.
2. Распаковать содержимое папки `SillyTavern-InnerWorld` из этого ZIP в папку расширения `inner-world`, обновив файлы и оставив собственные данные чата нетронутыми.
3. Перезагрузить SillyTavern (при проблеме со старым CSS — жёсткая перезагрузка страницы).
4. Открыть тестовый чат; последовательно проверить даты, повторный анализ, сцены сна, общую лавку, назначение коллекционных наград, предпочтения и сохранение вкладки настроек.
5. В «Главное» включить **«Режим диагностики в чате»**, при необходимости «Мини-инфоблок в чате»; проверить служебные записи без загрязнения истории. 
6. Сравнить результат на нескольких моделях и чатах. Если обнаружены сбои — не загружать патч как релиз без доработки.

**Технические решения и предположения из старых заметок не считаются источником истины:** необходим самостоятельный анализ зависимостей, регрессионные проверки, в первую очередь — тестирование в реальной SillyTavern. Вторая тема из сводки, **Haruspics Fusion**, не изменялась.
